# 📚 StudyHive

**StudyHive** is an interactive study platform built using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)**. It enhances academic productivity by integrating task management, study collaboration, and AI-powered note summarization in one unified workspace.

---

## 🚀 Overview

StudyHive provides a **comprehensive and scalable digital learning environment** that merges individual task accountability with shared academic growth. It enables students to organize their assignments, connect with peers, manage study sessions, and visualize progress efficiently.

---

## 🧠 Features

###  User Authentication & Profile
- Secure sign-up and login with JWT authentication.
- Profile editing, email verification, and interest tagging.
- Branch-wise distribution visualized via **Pie Chart**.

###  Study Buddy & Group Finder
- Find or create study groups based on subject, topic, or interest.
- Filter groups and buddies by preferences such as time and study mode.
- Community moderation through the **Report User** feature.

###  Assignment Tracker & To-Do List
- Track academic assignments by subject, priority, and due date.
- Manage daily tasks with search, filters, and overdue alerts.
- Visualize assignment priorities with **Bar Charts**.

###  Quiz Pool
- Create, share, and attempt quizzes.
- Supports MCQs with the ability to report questions.
- Subject-based quiz categorization and participation tracking.

###  AI-Based Notes Summarizer
- Upload typed notes to auto-generate concise summaries using a **HuggingFace API**.
- Organize notes and materials in a searchable repository.

### ⏱ Pomodoro Timer & Analytics
- Track study sessions using a built-in Pomodoro timer.
- View session logs and productivity analytics (daily time spent).

###  Feedback & Reporting
- Collects user feedback on productivity and usability.
- Feedback visualized through **Bar and Pie Charts**.
- Users can report bugs and inappropriate activity.

###  Dashboard & Visualizations
- Unified dashboard for assignments, tasks, and sessions.
- Real-time updates from Pomodoro logs and feedback.
- Integrated visual reports using **Recharts**.
